常见问题

还有疑问？

Windows 提示「已保护你的电脑」怎么办？

这个 exe 没有做代码签名，新发布的程序都会遇到。点「仍要运行」即可；如果只看到「不运行」，先点「更多信息」。源码完全公开，也可以自己从源码构建。

我能看到状态，别人却看不到？

这是 Discord 的隐私设置：在「用户设置 → 活动隐私」里打开「分享我的活动状态」，并在对应服务器的「隐私设置」里打开「活动状态」。在线状态也不能是「隐身」。

「精确进度」是什么？安全吗？

在托盘菜单开启后，程序会给网易云的快捷方式加上本地调试端口，从而读取网易云自己的播放进度。端口只监听 127.0.0.1，局域网内的其他设备无法访问；但本机上的其他程序可以通过它控制网易云，请只在自己信任的电脑上开启。

会收集我的数据吗？

不会。程序只做两件事：把播放状态发给你本机的 Discord 客户端（由 Discord 展示给好友），以及用歌曲 ID 向网易云的公开接口请求歌词（可以在菜单里关闭歌词）。

支持 macOS 或网页版吗？

目前只支持 Windows 上的网易云音乐 PC 客户端和 Discord 桌面客户端。
