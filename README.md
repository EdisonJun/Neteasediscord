# 网易云 / QQ 音乐 Discord 状态

把你正在**网易云音乐**或 **QQ 音乐**（Windows 客户端）里听的歌，显示成 Discord 的「正在收听」状态。

**介绍页：<https://edisonjun.github.io/Neteasediscord/>** · **下载：[最新版本](../../releases/latest)**

```
Listening to Netease Music            (放 QQ 音乐时显示 Listening to QQ Music)
┌──────┐  歌名
│ 封面 │  歌手 · 专辑
└──────┘  ♪ 正在唱的那一句歌词
          00:40 ━━━━━━━━━━━━ 03:32
          [   在网易云音乐中收听   ]    (QQ 音乐: 在QQ音乐中收听)
          [        下载插件        ]
```

- 支持 **网易云音乐** 和 **QQ 音乐**，状态标题会跟着显示 Netease Music 或 QQ Music
- 显示歌名、歌手、专辑、专辑封面和进度条，实时显示当前唱到的那句歌词
- 暂停后状态会跟着变，拖动进度条后进度和歌词也会同步
- 两个按钮：好友点「在…中收听」就能打开同一首歌，点「下载插件」会打开本项目的介绍页
- 在托盘后台运行，可以开机自启，不需要安装 Python；有新版本时会在托盘提醒

> 仅支持 **Windows**，以及网易云音乐 PC 客户端（在 3.1.x 上测试通过）、QQ 音乐 PC 客户端（在 22.x 上测试通过）和 Discord 桌面客户端。本项目与网易云音乐、QQ 音乐、Discord 官方没有任何关系。

## 下载与使用

1. 在[介绍页](https://edisonjun.github.io/Neteasediscord/)或 [Releases](../../releases/latest) 下载 exe，放到一个固定的文件夹里（开机自启会记住这个位置）
2. 打开 Discord 桌面客户端，然后双击 exe。右下角托盘会出现一个蓝色的小图标
3. 在网易云音乐或 QQ 音乐里播放一首歌，Discord 状态就会显示出来

Releases 里有两个内容一样的文件：`NeteaseDiscordRPC.exe`（固定文件名）和 `NeteaseDiscordRPC-<版本号>.exe`（介绍页下载的是这个，每个版本文件名不同，Windows 就不会显示旧版本缓存的图标）。

## 支持的播放器

| | 网易云音乐 | QQ 音乐 |
|---|---|---|
| 歌名 / 歌手 / 专辑 / 封面 | ✓ | ✓ |
| 实时歌词 | ✓ | ✓ |
| 暂停同步 | ✓ | ✓ |
| 拖动进度条后同步 | 需要开启[精确进度](#网易云开启精确进度推荐) | ✓ 不用设置 |
| 收听按钮 | 在网易云音乐中收听 | 在QQ音乐中收听 |

两个播放器同时开着时：显示**正在播放**的那个；都在播放时，显示**最近开始播放（或切歌）**的那个；都暂停时，显示最近播放过的那个。

## 托盘菜单

| 菜单项 | 作用 |
|---|---|
| 显示歌词 | 在第三行显示当前唱到的歌词 |
| 暂停时保留状态 | 暂停时显示「⏸ 已暂停」；关闭时暂停就清除状态 |
| 显示「在…中收听」按钮 | 按钮只有别人能看到，你自己看不到 |
| 显示「下载插件」按钮 | 别人点击后会打开本项目的介绍页 |
| 开机自动启动 | 登录 Windows 后自动在后台运行 |
| 开启 / 关闭精确进度 | 只和网易云有关，见下文 |

### 网易云：开启精确进度（推荐）

QQ 音乐会自己把播放进度报告给 Windows，不需要任何设置。网易云不会，所以默认情况下程序只能根据「歌曲开始播放的时间」和「网易云有没有在出声」来估算进度，拖动进度条后歌词会对不上。

点击托盘菜单里的 **「开启精确进度 (网易云调试端口)…」** 并允许管理员权限，程序会给网易云的快捷方式和开机自启项加上 `--remote-debugging-port=29222`。重启网易云后，程序就能直接读到网易云自己的播放进度和播放状态。

- 需要管理员权限，是因为开始菜单里的网易云快捷方式位于系统目录
- 网易云更新后可能会重置快捷方式；如果进度又变得不准，再点一次即可
- 不想用了，点 **「关闭精确进度 (还原网易云快捷方式)…」** 就会把快捷方式改回原样
- **安全提示**：调试端口只监听 `127.0.0.1`，局域网里的其他电脑访问不到。但开启后，本机上的其他程序可以通过这个端口控制网易云，并读取它的登录状态

## 常见问题

**别人看不到我的状态？**
程序是否工作正常，看你自己的个人资料卡就知道。如果你能看到而别人看不到，问题在 Discord 的隐私设置里：
- 用户设置 → 活动隐私 → 打开「分享我的活动状态」
- 右键服务器 → 隐私设置 → 打开「活动状态」（每个服务器可以单独设置）
- 在线状态不能是「隐身」

**杀毒软件报毒 / Windows 提示「已保护你的电脑」？**
这个 exe 是用 PyInstaller 打包的，没有做代码签名，所以容易被误报。点「仍要运行」即可（只看到「不运行」时，先点「更多信息」）。如果不放心，可以用下面的方法自己从源码运行或打包。

**怎么更新到新版本？**
有新版本时托盘会提醒。下载新版的 exe 直接双击；如果旧版本还在托盘里运行，会弹出提示问要不要改用新打开的这个，点「是」即可。

**QQ 音乐的歌没有封面 / 歌词 / 收听按钮？**
这些是按「歌名 + 歌手 + 时长」在 QQ 音乐网站上搜索得到的，切歌后 1～2 秒才会出现。极少数歌名对不上的歌（例如本地文件）会找不到，这时只显示歌名和歌手。纯音乐本来就没有歌词。

**状态没有显示？**
右键托盘图标，看最上面几行状态；也可以点「打开日志」查看详细信息。Discord 必须是桌面客户端，网页版不支持。

**设置文件在哪？**
`%APPDATA%\NeteaseDiscordRPC\config.json`。除了托盘菜单里的开关，还可以修改：

| 字段 | 说明 |
|---|---|
| `netease_name` / `qqmusic_name` | 状态标题「Listening to …」里显示的播放器名称，默认 `Netease Music` / `QQ Music` |
| `enable_qqmusic` | 是否支持 QQ 音乐，默认 `true` |
| `client_id` | Discord 应用 ID。一般不需要改；想用自己的应用，可以在 [Discord 开发者后台](https://discord.com/developers/applications) 创建后替换 |
| `cdp_port` | 网易云调试端口，默认 `29222`；设为 `0` 表示不使用 |
| `poll_interval` | 检测间隔（秒） |
| `pause_grace` | 网易云估算模式下，静音持续多少秒判定为暂停 |
| `check_updates` | 启动时是否向 GitHub 查询新版本，默认 `true` |

修改后需要从托盘退出程序再重新打开。

**会联网做什么？**
只有这几件事：把状态发给本机的 Discord 客户端；向网易云（`music.163.com`）或 QQ 音乐（`y.qq.com`）的公开接口查询封面、歌曲链接和歌词（可以关闭歌词）；启动时向 `api.github.com` 查询有没有新版本（`check_updates` 设为 `false` 即可关闭）。

## 卸载

1. 右键托盘图标，取消「开机自动启动」
2. 如果开启过精确进度，点「关闭精确进度 (还原网易云快捷方式)…」
3. 点「退出」，然后删除 exe
4. 删除设置和日志文件夹 `%APPDATA%\NeteaseDiscordRPC`

## 从源码运行 / 打包

需要 Python 3.10 或更高版本：

```bash
pip install -r requirements.txt
python app.py                              # 托盘模式
python netease_rpc.py -v                   # 命令行模式，输出调试日志
python -m unittest discover -s tests -v    # 运行测试
pip install -r requirements-build.txt && python build.py   # 打包到 dist/NeteaseDiscordRPC.exe
```

| 文件 | 内容 |
|---|---|
| `app.py` | 托盘程序入口、菜单、更新检查 |
| `netease_rpc.py` | 网易云读取、歌词、组装状态、推送到 Discord、多播放器选择 |
| `qqmusic.py` | QQ 音乐读取（系统媒体控件 + 网页接口） |
| `system.py` | 开机自启、网易云调试端口、单实例与接替 |
| `build.py` | PyInstaller 打包 |
| `docs/` | 介绍页（GitHub Pages 从 `main` 分支的 `/docs` 发布） |
| `tools/` | 生成介绍页字体子集 (`subset_fonts.py`) 和分享卡片 (`make_og_image.py`) |

发布新版本：推送 `v*` 格式的 tag（例如 `git tag v1.3.0 && git push origin v1.3.0`）。GitHub Actions 会先跑测试，再把 tag 写进程序的版本号、打包 exe 并发布到 Releases，不需要手动改版本号。

修改介绍页文字后，运行 `python tools/subset_fonts.py` 重新生成字体子集（只包含页面用到的字）；只改了 CSS / JS 时运行 `python tools/bust_cache.py`。两者都会给 `index.html` 里引用的 CSS / JS / 字体网址加上内容哈希，避免访客拿到新页面 + 旧缓存样式而错乱。

## 工作原理

| 信息 | 网易云音乐 | QQ 音乐 |
|---|---|---|
| 歌曲、播放/暂停 | 开启调试端口后：通过 Chrome DevTools 协议只读地查询网易云页面里的 redux store | Windows 系统媒体控件 (SMTC) |
| 播放进度 | 开启调试端口后：读取网易云进度条里隐藏的 `<input type=range>` | 系统媒体控件 |
| 后备方案 | 窗口标题 + 本地数据库 `webdb.dat` 的播放记录 + 音量合成器里的音频电平 | — |
| 封面 / 链接 | 网易云自带 | 按「歌名 + 歌手 + 时长」搜索 QQ 音乐网页接口 |
| 歌词 | `music.163.com/api/song/lyric` | `c.y.qq.com` 歌词接口 |

推送到 Discord：通过命名管道 `\\.\pipe\discord-ipc-N` 发送 `SET_ACTIVITY` 请求，状态类型为 Listening，`name` 字段决定标题里的播放器名称。受 Discord 频率限制（20 秒最多 5 次），歌词最多每 4 秒更新一次，歌曲或播放状态变化优先发送。

程序不会向网易云页面注册任何回调：网易云的原生层对每个事件只保留最后注册的那个处理函数，一旦注册，就会和网易云自己的进度条互相抢。
